# 视频修复工具 - Gradio界面使用说明

## 功能简介
这是一个基于Gradio的Web界面，用于修复损坏的流式MP4文件。通过重新封装视频流来解决视频播放问题。

## 安装要求

### 1. Python环境
- Python 3.7 或更高版本

### 2. FFmpeg
- 下载并安装FFmpeg: https://ffmpeg.org/download.html
- 确保FFmpeg已添加到系统PATH环境变量中
- 在命令行中运行 `ffmpeg -version` 验证安装

### 3. Python依赖
```bash
pip install -r requirements_gradio.txt
```

## 启动方式

### 方法1: 使用批处理文件（Windows）
双击 `start_gradio_app.bat` 文件

### 方法2: 命令行启动
```bash
python gradio_video_repair.py
```

## 使用说明

### 1. 访问界面
启动后，在浏览器中访问: http://localhost:7860

### 2. 上传文件
- 点击"上传MP4视频文件"按钮
- 选择需要修复的MP4文件

### 3. 设置参数
- **输入帧率**: 原始视频的帧率（默认30fps）
- **输出帧率**: 目标帧率（留空则与输入帧率相同）
- **视频编码**: 选择H.264或H.265编码

### 4. 开始处理
- 点击"开始修复"按钮
- 等待处理完成

### 5. 查看结果
- 在右侧预览修复后的视频
- 点击"下载视频"按钮保存文件

## 界面功能

### 文件上传区域
- 支持MP4格式文件
- 文件大小限制由Gradio默认设置

### 参数设置区域
- **输入帧率**: 1.0-120.0 fps，步长0.1
- **输出帧率**: 1.0-120.0 fps，步长0.1
- **视频编码**: H.264/H.265选择

### 结果展示区域
- 实时显示处理状态
- 视频预览播放器
- 一键下载功能

## 技术原理

1. **提取裸流**: 使用FFmpeg从损坏的MP4中提取视频裸流
2. **重新封装**: 将裸流重新封装成正常的MP4格式
3. **帧率转换**: 如需要，进行帧率转换和重新编码

## 注意事项

- 确保系统已正确安装FFmpeg
- 处理时间取决于视频大小和复杂度
- 支持H.264和H.265编码的视频
- 临时文件会自动清理

## 故障排除

### FFmpeg未找到
- 检查FFmpeg是否正确安装
- 验证PATH环境变量设置
- 重启命令行或IDE

### 处理失败
- 检查输入文件是否损坏严重
- 尝试调整帧率参数
- 查看错误信息进行诊断

### 界面无法访问
- 检查端口7860是否被占用
- 尝试更换端口号
- 检查防火墙设置
